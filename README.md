# Garment measurement method check

A dependency-free browser checklist for identifying a method mismatch before subtracting two garment dimensions. It includes five explicit conditions, counterexamples and a private record template. The tool does not inspect sources, recommend sizes, submit information or facilitate purchases.

Serve `index.html` as a static file. This project requires no build command, server, database, package installation, API key or external script. The GitHub Pages version uses the public project repository and its free project subpath.

Content and worked numbers are illustrative, AI-assisted editorial material maintained by Jay Moo. The contextual references share the same maintainer; referral relationships on the linked guides are disclosed on the page. No hands-on testing or product certification is claimed.
